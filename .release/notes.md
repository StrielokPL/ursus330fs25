## Ursus C-330 / C-330M 0.0.0.2

Compatibility and documentation baseline for the FS25 rebuild.

### Included
- project version reset to `0.0.0.2`,
- `StrielokPL` listed first in `modDesc.xml`,
- confirmed that the uploaded source already contains the tested Static Cabins compatibility fix,
- 18 cabin-related `movingTool` definitions removed,
- corresponding Interactive Control entries and cabin animations removed,
- only 3 technical tractor `movingTool` definitions remain,
- documented compatibility background involving Advanced Damage System and AIAutomaticSteering/AIASF,
- added technical baseline for later correction of mass, axle load distribution, engine, gearbox, ballast, PTO and linkage.

### Not yet changed
- engine torque curve and rated power,
- gearbox ratios and top speed,
- base mass and axle load distribution,
- factory ballast masses,
- tyre and traction calibration.

This is a prerelease intended as the clean starting point for the physics rebuild.
